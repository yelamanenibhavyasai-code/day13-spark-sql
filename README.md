# Day 13 - Spark SQL Basics

## Project Title
Customer Analytics Report using Spark SQL

## Objective

The objective of this project is to learn the basics of Spark SQL and DataFrame operations using customer purchase data.

## Technologies Used

- Scala 2.12.18
- Apache Spark 3.5.3
- Spark SQL
- sbt 2.0.7
- Java 17
- CSV
